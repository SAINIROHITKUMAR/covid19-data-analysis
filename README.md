# COVID-19 Data Analysis

This project analyzes global COVID-19 data using Python and data visualization libraries.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains global COVID-19 statistics including:

- Confirmed cases
- Deaths
- Recoveries
- Country and region information
- Date-wise data

## Analysis Performed

1. Global COVID-19 trend analysis
2. Top 10 countries by confirmed cases
3. Death vs recovery comparison
4. COVID-19 heatmap visualization

## Visualizations

The project includes:

- Line chart showing global COVID-19 trends
- Bar chart of most affected countries
- Heatmap comparison of top countries
